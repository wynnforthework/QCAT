### 2. 实时更新机制
```typescript
// WebSocket连接用于实时更新
const useRealTimeUpdates = (endpoint: string) => {
  const [data, setData] = useState(null);
  
  useEffect(() => {
    const ws = new WebSocket(`ws://localhost:8080${endpoint}`);
    
    ws.onmessage = (event) => {
      const update = JSON.parse(event.data);
      setData(update);
    };
    
    return () => ws.close();
  }, [endpoint]);
  
  return data;
};
```

### 3. 响应式设计

- **平板端**：两列布局，关键信息优先
- **移动端**：单列布局，卡片式展示

## 总结

针对双闭环架构，建议新增4个专用监控页面：

1. **双闭环系统总览** - 整体状态监控
2. **多策略工作流监控** - 策略优化过程监控
3. **交易执行系统监控** - 交易执行专用监控
4. **策略池状态管理** - 策略池详细管理

这些页面将与现有的自动化功能监控页面形成完整的监控体系，为双闭环架构提供全面的可视化支持。
